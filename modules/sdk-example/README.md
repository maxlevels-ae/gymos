# sdk-example

SDK Example: Proves the module system works

## Installation
Drop this folder into `modules/` and restart GymOS.

## API Endpoints
- `GET /api/sdk-example` — List all
- `GET /api/sdk-example/:id` — Get one
- `POST /api/sdk-example` — Create
- `PUT /api/sdk-example/:id` — Update
- `DELETE /api/sdk-example/:id` — Delete

## Permissions
- `sdk_example.view`
- `sdk_example.create`
- `sdk_example.edit`
- `sdk_example.delete`

## Events Emitted
- `sdk-example.created`
