# GymOS Purchase Module V1

Odoo-style purchase order management for GymOS.

## Flow
RFQ (draft) → Send → Confirm → Approve (optional) → Receive Goods → Create Bill → Post Bill

## Features
- Vendor management with price lists
- Product catalog with reorder tracking
- Full RFQ → PO workflow with approval
- Goods receipt notes
- Vendor bill creation from POs
- Purchase analysis reports
- Dashboard integration with alerts

## API Base
`/api/purchase/*`
